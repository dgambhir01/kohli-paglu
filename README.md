# Kohli Paglu

A living tribute page — a scrolling chronicle of Virat Kohli's career, from the West Delhi academy through IPL 2025 and Test retirement, built for every Kohli Paglu out there.

Single-page, no build step: open `index.html` directly, or serve it via GitHub Pages.

## Updating

The page is one static file (`index.html`) so it's meant to be extended as Kohli's career continues — new chapters, updated stats, the eventual full retirement post. Edit the chapter sections and the honours board list directly.

## Local preview

Just open `index.html` in a browser, or serve the folder:

```
npx serve .
```
